Privacy

By default this extension works fully offline. The built-in explainer runs on your machine and nothing leaves your machine at all: no error text, no page content, no usage data.

Optional BYOK mode below is the only exception. When you turn it on and save a key, the selected error text (and only that text) is sent to the provider you choose, OpenAI or Anthropic, so their model can explain it. Your key is stored only in chrome.storage.local on this machine and is never sent anywhere else.

Optional AI mode (BYOK)

Stored only in chrome.storage.local on this machine. It is sent only to the provider above, and only together with the error text you selected. Remove the key here any time to stop AI mode.
